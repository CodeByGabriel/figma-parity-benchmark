# Avisos de licença e redistribuição

- **dashboard**: código derivado do template *shadcn/ui dashboard* (licença MIT).
  Redistribuição permitida com atribuição.
- **Templates Preline (pendentes de inclusão)**: os templates do Preline UI possuem
  licença própria (alguns de uso pago). **Antes de incluir o código de qualquer um
  neste repositório público, verificar se a licença permite redistribuição.** Caso
  não permita, o projeto entra apenas com link + instruções de obtenção + as
  variantes como *patches/diffs*, sem o código integral.
- Os exports do Figma (`raw.json`, `figma.png`) descrevem designs criados pela
  própria equipe do projeto ou derivados de templates com licença compatível.
